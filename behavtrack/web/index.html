사료 주변 범위·분석 간격·촬영 조건이 다른 결과를 그대로 합산하지 마세요.

아직 촬영 결과가 없습니다. 카메라를 켜고 첫 관찰을 시작해 보세요.

사람의 판정과 비교

표본 검토

전체 시점에서 고정 난수로 최대 20개를 고릅니다. 검토 중 AI 판정을 숨겨 먼저 사람의 판단을 기록합니다. 이 검토만으로 모델이 검증됐다고 표시하지 않습니다.

케이지 전체 활동성

고정된 간격으로 케이지 영역에서 변한 픽셀의 비율을 계산합니다. 이동·그루밍 등을 포함한 영상 움직임 지표이며, 개체별 이동거리·속도는 계산하지 않습니다.

같은 촬영 구도의 다른 케이지는 이전 결과의 영역·관찰 길이를 복사하면 같은 조건으로 비교할 수 있습니다. 현재 영상에서 영역과 비교 블록이 맞는지 확인하세요.

케이지와 마우스가 보이는 범위를 표시하세요. 시계·케이지 밖의 사람은 제외합니다. 고정 배경에는 동물이 지나가지 않는 벽·장비 부분을 표시하세요.

원본 프레임을 불러와 케이지 영역을 표시하세요.

카메라 각도·거리·조명·케이지 구도가 같은 촬영에 같은 ID를 사용하세요.

관찰 시간대, 실험차수, 투여 후 경과시간 등 물 종류 외의 조건을 맞추세요.

사람의 준비·투여·청소·회수 장면을 제외한 관찰 구간을 맞추세요. 이 지표는 사람·도구의 움직임도 감지하므로 시작·중간·끝 원본 장면을 확인하세요.

기본 0.2초 간격 · 변화 기준 12/255 · 처리 너비 320픽셀. 큰 조명 변화·장면 변화·고정 배경 이동은 판정 불가입니다. 이 기준은 실제 실험 환경에서 검증해야 합니다.

그룹별 · 물 종류별 비교

비교할 결과를 선택하세요. 같은 케이지의 반복 영상은 유효 관측시간으로 가중해 한 케이지 값으로 합칩니다. 동일 원본·겹치는 구간을 중복 표본으로 세지 않습니다.

같은 촬영 설정·분석 조건·관찰 길이·마릿수·비교 블록만 함께 비교합니다. 그래프의 점 하나는 케이지 하나입니다. 평균과 케이지 간 표준편차를 표시하며, 유의성·물의 인과 효과를 자동 확정하지 않습니다.

이동거리·평균 속도 추정

케이지 전체를 비교합니다. 마우스의 중심점 경로를 계산하며, 겹침·검출 누락·불확실 연결은 판정 불가로 남깁니다. 정확도 미검증 상태입니다.

바닥 모서리를 왼쪽 위→오른쪽 위→오른쪽 아래→왼쪽 아래 순서로 클릭하세요.

1→2 변이 가로, 2→3 변이 세로입니다. 케이지 벽 상단이 아닌 바닥 모서리를 지정하세요.

실측 보정 전에는 픽셀 단위 미리보기만 계산합니다. 바닥 보정은 몸 높이·일어서기·렌즈 왜곡을 보정하지 않습니다.

명암 기준은 카메라·조명별로 확인하고 비교할 촬영에는 같은 값을 사용하세요. 반사·벽·꼬리가 마우스로 검출되지 않는지 추적 확인 영상에서 점검하세요.

마릿수는 촬영 원본의 조건을 사용합니다. 같은 케이지·카메라·관찰 조건에 같은 설정 ID와 비교 블록을 지정하세요.

그룹별·물 종류별 운동성 비교

기본 지표는 마리당 평균 속도(cm/s)입니다. 동일한 보정·마릿수·촬영·분석 간격·관찰 길이를 비교하며, 유효 추적 80% 미만·길이 미보정 결과는 제외합니다. 같은 케이지의 반복 촬영은 한 점으로 합쳐 케이지 n을 셉니다.

연구 사건과 케이지 접근 정답

연구 사건 기록 · 수정 이력





최종 표본은 AI 답과 무관하게 시간대별로 추출하며 다시 추출하지 않습니다. 빈 시간대와 미검토는 별도로 남습니다. 접근은 케이지 단위이며 실제 섭식 정답으로 복사되지 않습니다.






검출 상자 정답 (마릿수와 별도)
모든 동물이 보이는 장면에 직접 확인한 픽셀 상자를 입력합니다. 형식: [[x1,y1,x2,y2], …]. 기존 DeepLabCut 학습으로 내보낼 수 있습니다.





개체별 실제 섭식 정답
먼저 같은 원본의 다중 개체 DLC CSV 또는 SLEAP H5를 가져오세요. 개체의 입과 정체성을 직접 확인한 구간만 양성·음성으로 기록합니다.












자료 점검 → 후보 학습 → 독립 평가
같은 케이지의 모든 날짜와 동물은 한 분할에 둡니다. 한 케이지뿐이면 개발 또는 같은 케이지 다른 날짜 평가만 가능합니다.





평가 전에 고정할 허용 기준
모든 기준을 채우지 않으면 검증 완료로 표시하지 않습니다. 기준값은 연구자가 사전에 정하세요.






전체 점검·평가 기록
출력 확률은 보정되지 않은 모델 점수입니다. 소프트웨어 테스트 통과와 마우스 행동 정확도 검증은 별개입니다.


검출 누락 개선 · 기존 DeepLabCut 추가 학습
접근 마릿수는 상자 정답이 아닙니다. 원본 장면의 상자를 직접 작성한 뒤, 서로 다른 케이지를 학습/개발로 지정하세요. 최종 평가 자료는 포함할 수 없습니다.
포즈 모델의 관절 정답은 DLC에서 직접 작성합니다. 외부 결과는 ‘포즈 가져오기’로 연결합니다. 실제 영상과 정답이 없는 현재 추가 학습 성공이나 정확도를 보고하지 않습니다.




브라우저를 닫아도 녹화는 계속됩니다. 녹화를 끝내려면 ‘녹화 종료 · 원본 보존’을 누르세요.
저장 및 사용 조건
영상, 실제 촬영 시각, 고정한 관찰 조건, 분석 파일, 모델·코드 해시, 수동 검토 이력을 보관합니다. 분석은 이 컴퓨터에서 실행합니다. 원격 촬영을 사용하면 촬영 PC에서 지정한 이 서버로 원본을 암호화 전송합니다. 모델은 학술·비상업적 용도로 제공됩니다. 현재 분석은 CPU를 사용합니다.
