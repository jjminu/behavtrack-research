카메라는 이 컴퓨터에서 녹화합니다. 브라우저를 닫아도 촬영·전송은 계속됩니다.

촬영과 자동 분석 조건

케이지 전체 활동성을 자동 분석합니다.

이동거리·평균 속도 자동 분석

카메라 영역 표시에서 ‘바닥 네 모서리’를 선택해 왼쪽 위→오른쪽 위→오른쪽 아래→왼쪽 아래 순서로 클릭하세요. 케이지 바닥의 실제 크기를 입력합니다.

모든 마우스가 별도로 검출되고 연결이 확실한 구간만 계산합니다. 겹침·누락은 판정 불가이며, 확인된 거리·속도와 유효 추적 시간이 양쪽 화면에 표시됩니다. 정확도 미검증 상태입니다.

준비·투여·청소·회수 장면이 들어가지 않게 관찰 구간만 촬영하세요. 촬영이 끝날 때까지 원본 조건과 분석 영역은 고정됩니다.
